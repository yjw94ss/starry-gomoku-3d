# 星星五子棋 · 3D

一个用 **three.js** 做的 3D 五子棋小游戏，标准 **15×15** 棋盘，规则最简单：**五颗同色棋子连成一条线就赢**。
给小朋友玩的，所以没有计时、没有复杂规则，点一下就能落子。

👉 在线玩：**https://yjw94ss.github.io/starry-gomoku-3d/**

## 玩法

- 点一下棋盘交叉点就能落子，落下的棋子会先弹一下再站稳。
- 棋盘 **15×15（225 个交叉点）**，和正式比赛用的五子棋盘一样，几乎不可能下到平局。
- **五颗同色连成一条线（横、竖、斜都算）就赢**，连线会亮起金色光束。
- 顶部可以切换：**简单**（新手也能赢）/ **普通**（会认真下）/ **双人**（两个人轮流用同一台设备）。
- 悔棋、重开一局都在底部。
- 拖动可以旋转视角，滚轮或双指可以缩放，可以凑近看棋子。

## 特性

- **纯程序化建模**：棋盘、棋子、云朵、木纹全部用代码生成，没有一张外部图片，也不用下载模型。
- **单文件 700KB**：three.js 已内联，`index.html` 双击就能玩，断网也能玩。
- **音效也是代码生成的**：落子、获胜、按钮提示音都用 WebAudio 现场合成，没有音频文件。
- **手机适配**：竖屏会自动抬高视角并重新构图，棋盘不会被裁切。
- **性能轻**：约 20 次 draw call、1 万三角面，老手机也不卡。

```
src/js/scene.js     # 三维场景、动画、特效
src/js/app.js       # 交互、界面、音效

```

## 本地运行

```bash
python3 -m http.server 8123      # 然后打开 http://127.0.0.1:8123
python3 build.py                 # 改完 src/ 后重新构建
```

## 实现说明

- 棋盘取景不是写死相机距离，而是把棋盘四角投影到屏幕、反复迭代距离，
  直到整块棋盘稳稳落在「顶部标题」和「底部按钮」之间——所以横屏、竖屏、小窗口都不会裁切。
- 棋子的高光来自一张运行时生成的环境贴图（暗环境 + 三块柔光板），
  而不是把整个场景调亮，这样木纹和棋子的颜色不会被冲淡。
- 电脑对手是启发式评分：先看能不能赢、再看要不要挡，然后按「活三 / 冲四 / 活二」加权求和；
  简单模式会故意保留一定随机性和失误率，让小朋友有赢的机会。

## 验收

`qa/` 下是用真实 Chrome 跑的自动化脚本：

```bash
node qa/smoke.js    # 启动、落子、人机应答、悔棋、拖拽缩放、五连获胜、再开一局、手机端
node qa/edge.js     # 重复落子、连点、思考中悔棋、模式切换、窗口缩放、AI 逻辑
```

全部为 0 page error、0 console error。
